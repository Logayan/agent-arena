## 1. 隔离立场

SRE 视角不以“路由已经改名”为迁移完成标准，重点检查：

- Runtime 是否失败关闭；
- Session/Invocation 是否可因果追踪；
- Tool 是否可授权、去重、补偿和复读；
- Artifact 是否正式登记并可下载；
- 协作/Judge/Memory 是否改变平台状态；
- 暂停和故障恢复是否到达终态；
- OpenClaw 是否达到零流量、无旁路和可回滚退役条件。

## 2. 隔离判断及最终处理

### 2.1 采纳

- 当前 `claude_code / agent-sdk-bridge` 路由是平台事实；
- route attestation 与 historical retirement 必须分开；
- Runtime、Tool、Artifact、Memory、Recovery 需要稳定关联键；
- source attestation 与 raw source audit 必须分级；
- 文件发布与 Artifact 必须拆分；
- Run-wide 和 node-scoped 数量必须分别报告；
- 后端恢复在无 convergence 时不能判 PASS。

### 2.3 保留的质疑

- route attestation 不能证明 provider/model 端到端执行；
- `model=gpt-5.6-sol` 只能作为 attestation 字段值；
- all-allow Tool sample 没有授权 deny path；
- side-effect scan=`monitoring` 不是 exactly-once terminal receipt；
- platform source fingerprints 没有可独立读取的源文件字节；

- 没有 formal Artifact 就不能通过交付产物闭环；
- 当前节点没有五角色、Judge 和 intentional pause/resume。

## 4. Session 和 Tool 运行保障

### 4.1 Session

16 个 binding 都可反查到 `agent.turn.completed`，并核对 platform Session 与 SDK Session。当前节点 12 个 binding 覆盖两 actor 的独立、round 1、round 2 回合。

但没有 SDK open/continue/close 或 Invocation start/complete/fail，无法评价：

- SDK Session 泄漏；
- Invocation 取消；
- provider timeout；
- close hook；
- continuation/recreation 语义。

### 4.2 Tool

平台四事件链完整：

```text

```

可靠性限制：

- all 785 allow；
- no schema-deny / auth-deny；
- Tool event 无 sdk_session_id、invocation_id 和 result digest；
- 本节点 131 group 没有冻结 terminal binding；
- exactly-once 只看到 operation/idempotency key 和 monitoring scan，没有终态。

## 5. Artifact 和文件

最新两个公开 manifest 共 58 行：53 非删除、5 删除。45 非删除行可读取 export 原始字节并匹配；8 行只有 manifest＋platform file event 匹配，原始字节没有物化。

SRE 决定：

- 45 行可称 raw-byte reread；
- 8 行只能称 manifest/event correspondence；
- deletion marker 不因 export 仍保留旧字节而失效；
- 所有行均需有明确 adopt/revise/replace/reject 决定；
- 这些都不能替代 formal Artifact。

Artifact Registry 原始字节是 `[]`，因此 formal Artifact lifecycle 继续阻塞。

## 6. Memory、协作和 Judge

- Memory read/use 证明已有 Memory 被注入并使用；无 write governance；
- 两轮公开协作通过，但只有两 actor；
- 两个 cycle 均只有 `team.synthesis.started`；
- 无 Judge/rework/rejudge。

SRE 不接受把自然语言报告中的“Judge 建议”当作平台 Judge 事件，也不接受把 Memory 上下文当作本次写回。

## 8. SRE 退役门禁

OpenClaw 退役需要同时满足：

1. raw historical parity baseline；
2. all entrypoint route audit；
3. zero OpenClaw traffic observation window；
4. no bypass and single active writer；
5. Tool deny/timeout/retry/compensation tests；
6. formal Artifact and Judge negative path；
7. Memory write lifecycle；
8. intentional pause and backend failure convergence；
9. exactly-once external receipt；
10. governed rollback drill。

当前仅“current Claude-only route”满足部分条件，所以：

```text
openclaw_retirement=NOT_APPROVED
complete_migration=NOT_PROVEN
```
