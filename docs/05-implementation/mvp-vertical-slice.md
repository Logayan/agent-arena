# MVP 纵向切片实现记录

- 版本：0.1
- 日期：2026-07-23
- 状态：已实现并验证

## 1. 本次目标

在不依赖外部 LLM、Zep 或数据库的条件下，交付一条可运行纵向切片，验证：

- Client 与 API 工程能共同启动。
- 生产流状态能够按事件推进。
- Client 能实时接收 SSE 事件。
- 双栏、图谱和工作台三种观察模式可切换。
- 红队缺陷、修订、复测、评分和深度交互均有可视界面。
- 桌面与移动端没有横向溢出和明显遮挡。

## 2. 实现范围

### 2.1 后端

路径：`server/`

已实现：

- FastAPI 应用和 CORS。
- Run、Agent、Event、Defect 和 Score 数据模型。
- 内存 RunStore。
- SSE 事件流。
- 创建、读取、启动和取消演示运行 API。
- 九步模拟生产流：
  - 准备
  - 需求分析
  - 产品提案
  - 技术提案
  - 红队缺陷
  - 修订
  - 红队复测
  - 裁判评分
  - 完成并开放访谈

模拟器用于验证系统契约。真实模型接入后，Agent Worker 将产生相同事件和产物接口。

### 2.2 Client

路径：`client/`

已实现：

- Vue 3、TypeScript、Vite。
- 顶部生产流阶段、状态、Token 和估算成本。
- 双栏模式：
  - 事件筛选
  - 协作/对抗时间线
  - Agent 状态和任务
  - 红队缺陷
- 图谱模式：
  - Agent 节点
  - 正式产物节点
  - 缺陷节点
  - 状态图例
- 工作台模式：
  - 报告阅读
  - 六维评分
  - Agent 多选
  - 问卷输入和提交确认
- 开始、停止和创建新演示运行。
- 桌面和移动端响应式布局。

## 6. 当前限制

- 数据仅保存在 API 进程内存中。
- 模拟器使用固定事件，不调用真实 LLM。
- 问卷当前只进入 Client 本地交互队列。
- 图谱为领域关系的视觉原型，还没有可拖拽和查询能力。
- 暂未实现资料上传、真实知识检索和产物持久化。
- 暂未实现暂停和继续。
