## 16:14 长周期 Run 取消固定总时长与轻量轮询

用户确认真实 Agent 任务可能持续数天，固定 Run 总分钟数不应作为默认硬终止条件。执行策略改为固定总时长默认关闭：仅当 Workflow 明确声明 `enforce_run_time_limit=true` 时才应用 `max_run_minutes`；默认继续保留单次 Claude SDK 人物回合超时、`1800 → 3600 → 7200 → 14400` 自适应重试、Token/成本预算、人工取消、失败终态和心跳/停滞观测。总历史活动耗时仍保留用于审计，不再阻止新的恢复 epoch。

唯一验收 Run `run_bda13e93b2ea` 在 sequence 35729 被旧累计时限判为 `budget_exhausted`，没有覆盖历史证据。旧时限恢复入口现允许同 Run、同版本原地恢复；只重跑 `final_report_and_gap_list` 与下游 `final_independent_judgement`。恢复后事件增长到至少 35841，最终报告节点重新 running，证明 Claude Code SDK Worker 已继续真实行动。

同时确认前端对大 Run 的完整轮询会重复投影三万余事件并放大 SQLite 锁竞争。新增 `/api/platform/runs/{run_id}/state` 轻量状态接口，仅返回 Run 状态、任务摘要、最近事件、Artifact 数量和四类测试证据计数；运行中前端只合并轻量快照，终态后才读取一次完整卷宗。该接口不读取 Artifact 正文、不构建节点 dossier，也不覆盖历史事件。
