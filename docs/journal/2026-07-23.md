## 14. 内置示例与 Agent 配置边界

用户询问为什么 Client 显示“智能需求评审示例”，以及在哪里新增或配置 Agent。

已明确：

- Client 当前自动请求 `/api/demo`。
- 项目名称和运行标题由后端 `create_demo_run()` 固定创建。
- 七类 Agent 由 `AGENT_DEFINITIONS` 常量固定定义。
- 当前 Client 只能观察 Agent，尚不能新增或配置 Agent。
- Client 信息架构中已经设计角色配置模式，但对应页面、API 和动态编排尚待实现。

下一项产品功能应是项目创建、资料接入和 Agent 配置，而不是继续扩充固定演示数据。
