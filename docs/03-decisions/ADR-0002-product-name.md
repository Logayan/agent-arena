# ADR-0002：平台命名为 Agent Arena

- 状态：已接受
- 日期：2026-07-23

## 背景

平台已经具备首个可运行 Client 和 API，需要一个统一、可识别且能覆盖协作与对抗两种核心能力的产品名称。

## 决策

平台正式命名为：

> **Agent Arena**

中文名：

> **多智能体协演场**

## 命名含义

- `Agent` 明确产品主体是具有角色、工具、记忆和权限的智能体。
- `Arena` 不只表示竞争，也表示一个可以运行、观察和复盘多方互动的受控环境。
- “协演场”同时包含协作、推演、攻防演练和结果复盘，比单纯的“竞技场”更符合生产流场景。

## 使用规范

- 产品品牌、浏览器标题和文档主标题使用 `Agent Arena`。
- 首次中文介绍时使用“Agent Arena（多智能体协演场）”。
- 代码包名使用小写连字符形式 `agent-arena`。
- API 标题使用 `Agent Arena API`。
- 生产流、Agent 角色和具体项目名称不与平台品牌混用。

## 影响

- README、Client、API 和包名统一使用新名称。
- 历史调研文档中的原始项目描述保持不变。
- 后续视觉设计可以围绕“受控协演、证据链和攻防裁决”建立品牌系统。
